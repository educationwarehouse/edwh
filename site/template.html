What you get

Less yak-shaving, more shipping.

The boring parts of running a project, done the same way everywhere. Every command lives in a namespace, so edwh help always tells you where to look.

One CLI for every project

edwh finds your project's tasks.py, your plugins and your personal tasks, and puts them all under edwh (or ew for short). Hookable tasks with the same name run one after another, so a plugin or project can extend edwh up instead of replacing it.

edwh help          # everything, grouped by namespace
edwh local.seed    # this repo's tasks.py
edwh mp.list       # a plugin, in its own namespace
edwh restic.backup # another plugin
edwh my-alias      # ~/.config/edwh/tasks.py

Sudo, safely stored

edwh sudo checks your password once and keeps it in the system keyring, with an SSH-agent fallback when the keyring is locked.

Lint, format & test

Ruff and Ty out of the box, pytest with coverage, HTML reports on request. Tune it per project in pyproject.toml.

Releases without ritual

edwh plugin.release bumps, builds and publishes, and nudges you away from legacy build setups.

Powered by vommit

Worktrees

edwh worktree <branch> gives a branch its own checkout, ports and database, so you can run two versions side by side.

Your own tasks

Write a function, get a command.

Put a tasks.py in your project and edwh picks it up: listed in edwh help, with flags and help text like every built-in. Or hook into a built-in and let it do the heavy lifting first.

tasks.py
from edwh import improved_task as task


@task(help={"users": "number of fake users"})
def seed(ctx, users: int = 25):
    """Fill the dev database with fake users."""
    ctx.run(f"./bin/seed --users {users}")

tasks.py
from edwh import improved_task as task


@task(hookable=True)
def up(ctx, service=None):
    """Load fixtures once the containers run."""
    # what the built-in `up` returned
    services = ctx["result"]["services"]
    if "db" in services:
        ctx.run("./bin/load-fixtures")

How it works

Up and running in three steps.

1

Install

With pipx, uvenv or uv. Pick all plugins, or only the ones you need.

pipx install "edwh[plugins]"
2

Explore

Run edwh (or just ew) to see every command, or ask for help on one namespace.

edwh help plugin
3

Make it yours

Drop a tasks.py in your project, or global ones in ~/.config/edwh.

edwh local.<your-task>

Plugins

Add only what your project needs.

Each plugin gets its own namespace. Add or remove them any time. No reinstall needed.

edwh plugin.add multipass
One tasks.py per project, one muscle memory for all of them.
